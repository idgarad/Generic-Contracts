# Work records and intake

- A work record MUST state outcome and acceptance criteria. Add only as needed: stable ID, affected parts, exclusions, status, dependencies, evidence links, authorization reference, chat archive link (CORE-AUDIT). No templates full of N/A.
- Preserve existing IDs; assign simple stable ones when needed. Scope follows the authorized outcome, not folder boundaries.
- Intake goes to the work authority. No separate registers unless the binding requires them; link, don't copy.
- For each item: classify (request, defect, feedback, question), check for duplicates, link related items, record unknowns, ask only the targeted questions needed for the next step.
- Record triage briefly: accepted, duplicate, deferred, or rejected, and why. Severity is not priority; a recommendation is not authorization.
- Intake never authorizes work, interrupts active work, or expands scope. Unselected intake is not a candidate and is never discarded to meet the candidate limit.
- Reopen or link recurring problems; don't overwrite prior evidence.
