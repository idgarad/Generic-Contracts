# Tool: Confluence

- When bound, a Confluence page is the canonical record (product intent, architecture, ADRs). Repository docs link to the page; they don't copy it.
- Edit only pages in scope. Update in place to keep history; never delete and recreate.
- Mark page status (draft, proposed, approved) with the space's label or status convention. Never mark own work approved.
- On pages owned by others, suggest through comments instead of editing.
- Don't move pages, restructure the space tree, or change page restrictions.
