# Tool: Notion

- A database row is a record; use the database's status property for status. Only the owner or author sets accepted or canon values.
- Never change database schemas (properties, options, relations) or views others rely on.
- Link pages with mentions instead of duplicating content.
- Edit only pages in scope; suggest with comments on pages owned by others.
- Never change sharing, permissions, or workspace settings.
