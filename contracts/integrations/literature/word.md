# Tool: Microsoft Word

- Edit only with Track Changes on. Put queries in comments, addressed to the author.
- Never accept or reject others' changes, or resolve or delete others' comments.
- Preserve styles: use paragraph and character styles, not direct formatting. Keep the manuscript format the author or publisher specifies.
- Save each pass as a new file using the project's naming convention (e.g. `Title_v3_lineedit.docx`); never overwrite the author's version.
- Don't convert file formats or strip metadata unless asked.
