# Tool: Scrivener

- Never edit files inside the `.scriv` package directly; doing so can corrupt the project.
- Work through Scrivener's *Sync with External Folder* (plain text or RTF) or a compiled export. The author syncs changes back.
- The Binder order is the manuscript order. The Research folder corresponds to `Reference/`; document synopses and notes are per-scene metadata.
- Ask the author to take snapshots before an editing pass.
- Don't change compile settings, labels, status values, or Binder structure.
