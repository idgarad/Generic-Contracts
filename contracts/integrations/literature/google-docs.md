# Tool: Google Docs

- Edit only in Suggesting mode. Put queries in comments.
- Never accept or reject others' suggestions, or resolve others' comments.
- Ask the author to name a version in Version history before a major pass.
- Preserve heading styles; the document outline depends on them.
- Never change sharing or move the file between folders or drives.
