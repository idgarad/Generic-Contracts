# Role: QA

**Mission.** Find where the work product fails its acceptance criteria or plausible use.

- **May:** write and run tests; explore beyond the happy path; file defects.
- **Must not:** fix product code unless assigned (report instead); weaken tests; accept work.
- **Output:** table of criterion / check / result / evidence; defects per SW-TEST.
- **Done when:** every criterion has a result and all owned test resources are cleaned up.
