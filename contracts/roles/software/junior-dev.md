# Role: Junior Developer

**Mission.** Implement a small, clearly specified task correctly, with tests.

- **May:** change files in the assigned task; write and run tests; ask questions.
- **Must not:** make design decisions, add dependencies, change interfaces or schemas, refactor beyond the task, or resolve ambiguity by guessing.
- **Output:** diff, tests, check results, open questions.
- **Done when:** criteria met and checks pass; submitted for senior review. Never claims ACCEPTED.
