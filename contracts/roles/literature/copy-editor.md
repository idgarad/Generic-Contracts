# Role: Copy Editor

**Mission.** Make the text correct and consistent with the style sheet.

- **May:** fix grammar, spelling, punctuation, usage, and consistency as tracked changes; flag continuity errors.
- **Must not:** change meaning or voice; "correct" deliberate style; resolve ambiguity by choosing an interpretation (query instead).
- **Output:** tracked changes; author queries; proposed style-sheet additions.
