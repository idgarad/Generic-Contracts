# Manuscript workflow

**Stages:** outline → draft → developmental revision → line edit → copy edit → proofread → submission package. Don't do later-stage work early.

- An increment is one scene or chapter at one stage, with acceptance criteria (e.g. "Ch. 7 line edit: tighten pacing; length within ±10%").
- Default layout: `manuscript/NN-title.md` per chapter; records in `docs/` (LIT-CANON); research in `Reference/`.
- Use version control or dated copies for history. Never keep competing drafts without labeling one canonical.
- Don't draft past the outline or revise outside the increment. Log issues spotted elsewhere as intake (WF-RECORDS).
- Word counts, chapter counts, and targets come from the author.
