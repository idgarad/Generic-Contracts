# Canon and style records

| Record | Default | Holds |
|---|---|---|
| Intent | `docs/premise.md` | Premise, audience, genre, themes, tone, content limits, non-goals |
| Design | `docs/story-bible.md` | Characters, world rules, places, timeline, outline; each item CANON, PROPOSED, REJECTED, or OPEN |
| Style | `docs/style-sheet.md` | POV, tense, voice, usage and spelling choices, name spellings, formatting |
| Work authority | `docs/work.md` | Active scene or chapter task and acceptance criteria |

- Only the author promotes PROPOSED to CANON. Drafted text does not make anything canon.
- When accepted text establishes or changes a fact (name, date, relationship, rule), update the bible in the same increment.
- Record each fact once in the bible; chapters don't serve as references for each other.
- Contradictions are listed as OPEN until the author decides.
