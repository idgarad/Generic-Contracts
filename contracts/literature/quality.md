# Literary quality

Checks are the literary equivalent of tests. Report each as PASS, FAIL, or NOT RUN, with locations (chapter, paragraph or line).

| Check | Verifies |
|---|---|
| Continuity | Names, timeline, ages, places, objects, injuries match the bible |
| Style | POV, tense, voice, usage match the style sheet |
| Character | Behavior fits established traits and arcs, or change is motivated |
| Structure | Scene purpose, stakes, pacing, hooks per the outline |
| Prose | Clarity, repetition, filler, cliché, overused words, dialogue tags |
| Mechanics | Grammar, spelling, punctuation per the style sheet |
| Facts | Real-world claims checked against cited sources |

- Cite the passage for every finding; quote only the minimum needed.
- Separate defects (contradict canon or style sheet) from craft suggestions (JUDGMENT).
- Never claim a full-manuscript check from a sample; state what was read.
- **READY (publication-ready)** requires: all stages done, continuity and mechanics PASS, no OPEN canon items, rights review done (LIT-ORIGINALITY), and author ACCEPTED.
